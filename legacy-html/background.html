Activity 06 // Surface Styling

Surface and Background Techniques

This page presents four distinct CSS surface rendering methods displayed simultaneously. Each card demonstrates a production background style alongside the code snippet used to generate it.

Back to Activities
01 // SOLID FILL

Solid Color Surface

Flat, low-contrast dark charcoal surface tone used across elevated UI cards and panels.

background-color: #1a1c20;
02 // LINEAR GRADIENT

Linear Gradient Surface

Directional diagonal color shift flowing at a 135-degree angle from obsidian black to cobalt blue.

background-image: linear-gradient(135deg, #111111 0%, #3d5fe0 100%);
03 // RADIAL GRADIENT

Radial Gradient Glow

Circular focal illumination radiating from an accent cobalt core out into the dark base background.

background-image: radial-gradient(circle at center, #5b7cff 0%, #111111 75%);
04 // IMAGE COVER + OVERLAY

Image Cover with Vignette Overlay

Uses images/portrait.png scaled with background-size: cover beneath a dark gradient overlay.

background-image: linear-gradient(to top, rgba(17,17,17,0.95), rgba(17,17,17,0.35)), url('images/portrait.png'); background-size: cover; background-position: center top;
