Webpage Specification and Grading Rubric

This page defines the formal evaluation criteria and architectural blueprint for the final Introduction to Computing web portfolio. It outlines the percentage weights for design, content, and functionality.

Back to Activities
Official INTCOMP Final Project Evaluation Rubric
Evaluation Criterion Description and Standards Weight
Design & Presentation Overall visual appeal, consistent dark theme styling, typographic hierarchy using Geist and Geist Mono, clear negative space, and responsive adaptation across 360px, 768px, and 1280px viewports without horizontal scroll. 50%
Content & Completeness Authentic student facts, complete 11-page structure, real course schedule data, valid image alternate text, complete education timeline with honors, and accurate documentation across all 10 activities. 25%
Functionality & Standards Semantic HTML5 elements, pure CSS3 interactivity (:target lightbox, hover dropdown, print stylesheet), 44px minimum tap targets, zero JavaScript dependencies, and zero broken links across all pages. 25%
Total Evaluation Score 100%
