Semantic Inline Formatting

Paragraph, Text Formatting Tags & Lists

Demonstration of semantic inline elements including bold, italic, underline, strikethrough, highlights, small print, sub/super scripts, blockquote, code, and lists.

<p> Paragraph

A standard paragraph demonstrating regular body text sizing and comfortable reading line-height.

<strong> Bold

Used to represent strong importance or urgency in user interface copy.

<em> Italic

Used for stress emphasis or specialized terms that change sentence inflection.

<u> Underline

Represents an unarticulated, non-textual annotation such as a spelling highlight.

<s> Strikethrough

Represents contents that are no longer accurate or relevant to current specifications.

<mark> Highlight

Highlights relevant text using the browser mark tag for reference.

<small> Small Text

Fine print text used for side comments, legal disclaimers, and metadata notes.

<sub> & <sup> Scripts

Chemical formulas like H2O and mathematical exponents like 210 = 1024.

<code> Monospace Code

Inline code snippets such as box-sizing: border-box; and key CSS selector syntax.

<blockquote> Quotation
"Good web design starts with clear semantic structure, readable typographic rhythm, and accessible user interfaces that work without client-side script overhead."
